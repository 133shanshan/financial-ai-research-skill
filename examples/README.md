# 输出示例目录

本目录存放"金融AI投研"Skill 的输出示例，用于指导 AI 生成符合金融分析规范的投资报告。

## 文件命名规范

- AI 选股示例：`ai-stock-selection-example.md`
- 货币政策分析示例：`monetary-policy-analysis-example.md`
- 资产配置示例：`asset-allocation-example.md`
- 行业研究示例：`industry-research-example.md`
- 宏观数据分析示例：`macro-data-analysis-example.md`
- 市场环境分析示例：`market-environment-example.md`
- 市场情绪分析示例：`sentiment-analysis-example.md`

## 使用示例

当用户请求生成某类分析报告时，AI 应首先读取对应的示例文件，了解预期的格式、风格和结构，然后生成符合要求的输出。

## 注意事项

1. 示例文件应包含完整的分析报告结构（标题、摘要、分析、结论、免责声明）
2. 示例应展示如何使用 `${CLAUDE_SKILL_DIR}/references/` 中的方法论文件
3. 示例应展示如何正确标注数据来源和获取时间
