# 常见错误案例库

> 本文件记录「金融AI投研」Skill执行过程中的常见错误、失败案例、以及错误修正方法。
> **目的**：帮助AI避免重复错误，提升分析质量。

---

## 错误分类

### 一、数据获取错误

#### 错误1：股票代码格式错误
**错误示例**：
```python
# ❌ 错误
ak.stock_zh_a_hist(symbol="600519", ...)

# ✅ 正确
ak.stock_zh_a_hist(symbol="sh600519", ...)
```

**修正方法**：
- 上交所股票：加 `sh` 前缀（6开头）
- 深交所股票：加 `sz` 前缀（00/30开头）
- 北交所股票：加 `bj` 前缀（8开头）

**历史案例**：
- `600519` → 应为 `sh600519`（贵州茅台）
- `000001` → 应为 `sz000001`（平安银行）
- `300750` → 应为 `sz300750`（宁德时代）

---

#### 错误2：日期格式错误
**错误示例**：
```python
# ❌ 错误
start_date="2024-01-01"  # AkShare不接受连字符

# ✅ 正确
start_date="20240101"
```

**修正方法**：
- AkShare日期格式：`YYYYMMDD`（无连字符）
- month参数格式：`YYYY-MM`（仅month参数用连字符）

---

#### 错误3：数据为空（股票已退市）
**错误示例**：
```python
df = ak.stock_zh_a_hist(symbol="sh600002", ...)
# 返回空DataFrame（股票已退市）
```

**修正方法**：
- 获取数据后，先检查 `df.empty`
- 如果为空，提示用户"该股票可能已退市或代码错误"
- 建议用户用 `ak.stock_zh_a_spot_em()` 搜索正确代码

---

### 二、分析方法错误

#### 错误4：语义打分尺度错误
**错误示例**：
```
政策语义分：+80分（应为-1.0 ~ +1.0）
```

**修正方法**：
- 语义分范围：`-1.0`（极度收紧）~ `+1.0`（极度宽松）
- 不是百分制！不是五分制！
- 参考 `module2-monetary-policy.md` 的打分规则

**正确示例**：
```
政策语义分：+0.3（温和宽松）
```

---

#### 错误5：情绪评分计算错误（未加权）
**错误示例**：
```python
# ❌ 错误（简单平均）
sentiment_score = (news_score + social_score) / 2
```

**修正方法**：
- 必须按照 `module7-sentiment-pulse.md` 的权重计算
- 新闻情绪：40%，社交媒体：30%，资金流向：20%，技术指标：10%

**正确示例**：
```python
sentiment_score = news_score * 0.4 + social_score * 0.3 + fund_score * 0.2 + tech_score * 0.1
```

---

#### 错误6：资产配置权重之和≠100%
**错误示例**：
```
股票：50%
债券：40%
商品：20%
# 总和=110%，错误！
```

**修正方法**：
- 所有资产配置权重之和必须=100%
- 使用 `module3-asset-allocation.md` 的AI动态权重融合方法
- 检查：`sum(weights) == 1.0`

### 三、输出格式错误

#### 错误7：未生成 .docx 文件
**错误示例**：
```
AI：根据分析，贵州茅台的评级是买入...（直接在对话中输出）
```

**修正方法**：
- **默认输出格式：Word（.docx）**
- 必须使用 `deliver_attachments` 将 .docx 文件发送给用户
- 仅在用户明确要求 Markdown 时，才输出 .md 格式

---

#### 错误8：未标注数据来源和获取时间
**错误示例**：
```
贵州茅台最新价：1688.00元
```
（未标注数据来源和获取时间）

**修正方法**：
- 所有数据**必须标注来源和获取时间**
- 格式：
  ```
  数据来源：AkShare（东方财富）
  数据获取时间：2026-05-18 16:30:00
  数据更新频率：实时（延时15秒）
  ```

---

### 四、逻辑错误

#### 错误9：忽略政策取向，仅看技术面
**错误示例**：
```
AI：贵州茅台技术指标金叉，建议买入。
（但实际：中央政治局公报刚说"抑制资本无序扩张"，政策收紧）
```

**修正方法**：
- **A股是政策市！** 政策取向优先级 > 技术面
- 必须先读取 `module2-monetary-policy.md`
- 政策收紧时，即使技术面好看，也要谨慎

---

#### 错误10：未发现情绪背离信号
**错误示例**：
```
AI：市场情绪乐观（+0.6），建议买入。
（但实际：价格上涨，成交量萎缩 → 背离信号，即将反转）
```

**修正方法**：
- 必须按照 `module7-sentiment-pulse.md` 检查背离信号
- 常见背离：价涨量缩（看跌）、价跌量涨（看涨）
- 发现背离后，降低置信度，提示用户风险
