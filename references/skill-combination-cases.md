# Skill联合应用案例

## 概述

本文件记录**金融AI投研Skill**与其他Skills的联合应用案例，展示多Skill协同工作流程。这些是课程答辩的关键展示内容。

---

## 案例1：深度研报生成

### 涉及Skills
- **金融AI投研**（主Skill）
- **hv-analysis**（纵横分析法）

### 应用场景
用户需要对某个行业、公司或投资策略进行**深度研究**，单个Skill的分析深度不足，需要联合应用。

### 工作流程

```
用户请求："帮我深度分析一下新能源汽车行业"
    │
    ▼
【金融AI投研】模块四：行业基本面研究
    ├── 读取 methodology/module4-industry-research.md
    ├── 采集数据（AkShare：行业财务数据、竞争格局）
    ├── 生成基础分析报告（.docx）
    └── 判断：需要更深度的纵向叙事和横向对比 → 触发 hv-analysis
            │
            ▼
【hv-analysis】纵横分析法
    ├── 纵向轴：追踪行业从诞生到当下的完整生命历程（叙事故事）
    ├── 横向轴：与竞品/同类行业进行系统性对比
    ├── 横纵交汇洞察：产出独到洞察
    └── 输出：排版精美的PDF研究报告（10,000-30,000字）
            │
            ▼
【合并输出】
    ├── 基础分析报告（.docx）→ 来自金融AI投研
    └── 深度研究报告（.pdf）→ 来自 hv-analysis
```

### 触发条件
- 用户说"深度分析"、"研究报告"、"纵横分析"、"完整研究"、"对比研究"
- 金融AI投研分析结果需要更完整的纵向叙事和横向对比
- 需要产出PDF格式的深度研究报告（而非简短的.docx分析结论）
- 研究对象是具体公司、产品、或金融概念，需要追时间深度+同期广度

### 示例对话

**用户：** "帮我深度分析一下新能源汽车行业，我要做投资决策。"

**AI执行流程：**
1. 【金融AI投研】模块四：行业基本面研究
   - 采集数据：新能源汽车行业财务数据、竞争格局、政策环境
   - 生成基础分析报告：`新能源汽车行业分析_基础版.docx`
2. 【hv-analysis】纵横分析法
   - 纵向轴：追踪新能源汽车行业从2009年"十城千辆"到2026年的完整发展历程
   - 横向轴：对比新能源汽车 vs. 传统燃油车 vs. 氢能源汽车
   - 横纵交汇洞察：产业政策退坡后的市场格局变化、技术路线分歧
   - 输出：`新能源汽车行业深度研究报告.pdf`
3. 【合并输出】
   - 交付两个文件：基础版.docx（快速阅读）+ 深度版.pdf（决策参考）

### 协同价值
- **金融AI投研**：提供专业的金融分析框架、数据采集、基础报告生成
- **hv-analysis**：提供深度的纵横分析法、叙事性洞察、PDF排版输出
- **1+1>2**：基础分析 + 深度洞察 = 完整投资决策依据

## 案例2：实时机会捕捉

### 涉及Skills
- **金融AI投研**（主Skill）
- **AnySearch**（实时数据搜索）

### 应用场景
用户需要**捕捉实时市场机会**，需要最新行情、新闻、宏观数据、政策公告，单个Skill的数据获取能力有限。

### 工作流程

```
用户请求："帮我看看今天有什么投资机会"
    │
    ▼
【AnySearch】实时数据获取
    ├── 搜索实时行情（A股、港股、美股、期货）
    ├── 搜索最新新闻（财经新闻、公司公告、政策发布）
    ├── 搜索宏观数据（CPI、PPI、PMI、GDP）
    └── 返回结构化数据 → 传递给金融AI投研
            │
            ▼
【金融AI投研】模块二/三/六/七：市场分析
    ├── 模块二：AI货币政策语义分析（解读政策文本）
    ├── 模块三：国信AI资配框架（动态权重资产配置）
    ├── 模块六：市场环境分析（全球市场风险评估）
    ├── 模块七：市场情绪脉搏（聚合新闻与社交信号）
    └── 输出：投资机会报告（.docx）
            │
            ▼
【合并输出】
    └── 实时投资机会报告（含数据来源标注、免责声明）
```

### 触发条件
- 用户说"实时行情"、"最新数据"、"今天机会"、"政策影响"
- 需要获取实时或当日数据（AkShare历史数据无法满足）
- 需要搜索最新财经新闻、公司公告、政策发布
- 需要宏观数据实时更新（CPI、PPI、PMI、GDP）

### 示例对话

**用户：** "帮我看看今天有什么投资机会，央行今天有发布什么政策吗？"

**AI执行流程：**
1. 【AnySearch】实时数据获取
   - 搜索实时行情：A股今日涨跌幅、成交量、资金流向
   - 搜索最新新闻：央行今日是否发布政策公告
   - 搜索宏观数据：最新PMI、CPI、PPI数据
   - 返回结构化数据
2. 【金融AI投研】模块二/三/六/七
   - 模块二：AI货币政策语义分析（解读央行今日政策文本）
   - 模块三：国信AI资配框架（根据实时数据调整资产配置权重）
   - 模块六：市场环境分析（全球市场风险评估）
   - 模块七：市场情绪脉搏（聚合今日新闻与社交信号）
   - 输出：`今日投资机会报告.docx`
3. 【合并输出】
   - 交付报告：含数据来源标注、免责声明、投资建议

### 协同价值
- **AnySearch**：提供实时数据获取能力（行情、新闻、宏观数据、政策公告）
- **金融AI投研**：提供专业的金融分析框架、投资策略生成
- **1+1>2**：实时数据 + 专业分析 = 可操作的投资建议

## 案例3：基金尽调报告

### 涉及Skills
- **金融AI投研**（主Skill）
- **hv-analysis**（纵横分析法）
- **ima-skills**（浑水调研知识库）

### 应用场景
用户需要对某只基金进行**深度尽调**，需要基金历史表现、基金经理背景、投资策略、风险分析，以及行业横向对比、外资研报观点。

### 工作流程

```
用户请求："帮我尽调一下易方达蓝筹精选混合（005827）"
    │
    ▼
【金融AI投研】模块八：顶级基金深度分析
    ├── 读取 methodology/module8-fund-analysis.md
    ├── 采集数据（AkShare：基金基本信息、净值走势、持仓明细、财务指标）
    ├── 生成基础尽调报告（.docx）
    └── 判断：需要更深度的纵向叙事和横向对比 → 触发 hv-analysis
            │
            ▼
【hv-analysis】纵横分析法
    ├── 纵向轴：追踪基金从成立到当下的完整生命历程（基金经理变更、投资策略调整、历史业绩表现）
    ├── 横向轴：与同类基金（易方达蓝筹精选 vs. 易方达消费行业 vs. 易方达中小盘）进行系统性对比
    ├── 横纵交汇洞察：基金经理投资风格稳定性、策略有效性、风险调整后的收益表现
    └── 输出：基金深度研究报告（.pdf）
            │
            ▼
【ima-skills】浑水调研知识库
    ├── 搜索浑水调研知识库（KB ID: 7297249738490228）
    ├── 获取外资研报观点、产业专家交流、卖方电话会记录
    └── 返回高质量调研资料 → 补充到基金尽调报告
            │
            ▼
【合并输出】
    ├── 基础尽调报告（.docx）→ 来自金融AI投研
    ├── 深度研究报告（.pdf）→ 来自 hv-analysis
    └── 外资研报观点（.docx）→ 来自 ima-skills
```

### 触发条件
- 用户说"基金尽调"、"深度分析基金"、"基金对比"、"外资研报"
- 需要获取基金历史表现、基金经理背景、投资策略、风险分析
- 需要行业横向对比（同类基金对比）
- 需要外资研报观点、产业专家交流、卖方电话会记录

### 示例对话

**用户：** "帮我尽调一下易方达蓝筹精选混合（005827），我想买这只基金。"

**AI执行流程：**
1. 【金融AI投研】模块八：顶级基金深度分析
   - 采集数据：基金005827基本信息、净值走势、持仓明细、财务指标
   - 生成基础尽调报告：`易方达蓝筹精选混合_尽调报告.docx`
2. 【hv-analysis】纵横分析法
   - 纵向轴：追踪基金从2018年成立到2026年的完整发展历程（基金经理变更、投资策略调整、历史业绩表现）
   - 横向轴：对比易方达蓝筹精选 vs. 易方达消费行业 vs. 易方达中小盘
   - 横纵交汇洞察：基金经理投资风格稳定性、策略有效性、风险调整后的收益表现
   - 输出：`易方达蓝筹精选混合_深度研究报告.pdf`
3. 【ima-skills】浑水调研知识库
   - 搜索浑水调研知识库（KB ID: 7297249738490228）
   - 获取外资研报观点、产业专家交流、卖方电话会记录
   - 返回高质量调研资料：`外资研报观点_易方达蓝筹精选.docx`
4. 【合并输出】
   - 交付三个文件：基础尽调.docx + 深度研究.pdf + 外资研报.docx

### 协同价值
- **金融AI投研**：提供专业的基金分析框架、数据采集、基础报告生成
- **hv-analysis**：提供深度的纵横分析法、叙事性洞察、PDF排版输出
- **ima-skills**：提供外资研报观点、产业专家交流、卖方电话会记录
- **1+1+1>3**：基础分析 + 深度洞察 + 外资观点 = 完整基金尽调依据

## 总结：Skill联合应用的核心价值

| 案例 | 涉及Skills | 核心价值 |
|------|-------------|----------|
| 深度研报生成 | 金融AI投研 + hv-analysis | 基础分析 + 深度洞察 = 完整投资决策依据 |
| 实时机会捕捉 | 金融AI投研 + AnySearch | 实时数据 + 专业分析 = 可操作的投资建议 |
| 基金尽调报告 | 金融AI投研 + hv-analysis + ima-skills | 基础分析 + 深度洞察 + 外资观点 = 完整基金尽调依据 |

**关键要点：**
1. **主Skill**：金融AI投研（负责核心金融分析）
2. **辅助Skills**：hv-analysis、AnySearch、ima-skills（负责增强特定能力）
3. **协同方式**：主Skill判断需要增强能力时，自动触发辅助Skills
4. **输出合并**：多个Skills的输出合并为一个完整报告
