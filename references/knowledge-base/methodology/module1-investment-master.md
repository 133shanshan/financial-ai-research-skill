# 方法论知识库 — 模块一：AI投资大师智能体

> LLM Wiki 模式：中间知识层，由 AI 和人工共同维护。
> 本文档沉淀模块一的核心方法论、回测数据、参数建议。

---

## 框架概览

本模块源自国金证券对开源项目 AI hedge fund 的改进，核心思路是**用多智能体系统模拟投资公司的完整投研流程**，让11位海外投资大师的投资理念通过大模型在A股市场落地。

---

## 三重角色架构

| 角色 | 职责 | 是否用大模型 |
|------|------|-------------|
| **分析师Agent** | 基础研究/大师分析，产生交易信号 | 大师Agent用大模型，基础分析师不用 |
| **风险管理Agent** | 计算仓位上限、剩余现金、最大可买股数 | 否，纯客观数据 |
| **投资组合管理Agent** | 综合所有信号，生成最终交易决策 | 是，大模型做综合判断 |

---

## 技术栈

| 组件 | 作用 |
|------|------|
| **Langchain** | 提供Agent、Chain、Memory等核心组件 |

## 工作流程

```
用户提问（如：用巴菲特Agent分析特变电工）
    ↓
Step 0【必须先做】: 用 akshare 拉取真实数据
  - ak.stock_zh_a_spot_em()  → 筛选目标股票实时行情
  - ak.stock_zh_a_hist(symbol=, adjust="qfq") → 历史K线
  - ak.stock_financial_abstract_ths(symbol=, indicator="按报告期") → 财务指标
  - 将数据整理为：ROE/毛利率/负债率/营收增速 等大师评分所需指标
    ↓
Step 1: 工作流编排(StateGraph) → 将真实数据注入分析师Agent
Step 2: 并行研究 → 大师Agent基于真实数据（而非空框架）生成信号
Step 3: 风险管理 → 基于真实股价计算仓位上限
Step 4: 最终决策 → 输出带数据支撑的买入/卖出/持有信号
```

**修改后的工作流程（加入数据获取）：**

1. **数据获取（新增，必须先做）**：用 akshare 拉取目标股票的实时行情、历史K线、财务指标
2. **用户启动**：将真实数据作为输入，读取选定分析师名单
3. **工作流编排**：AgentState 中注入真实财务数据，而非空框架
4. **并行研究**：大师Agent 用真实ROE/毛利率/负债率等指标评分，再生成信号
5. **风险管理**：用真实股价和账户资金计算仓位上限
6. **最终决策**：综合真实数据信号，输出买入/卖出/持有，并附数据依据

### 推导链强制模板（P0·可审计，v3.1.0 新增）

**所有分析结论必须按以下三段式呈现，缺一不可：**

| 段 | 必须包含 | 示例（承接 13 项指标加权评分） |
|------|---------|------|
| **证据（Evidence）** | 关键财务数据 + 来源 + 获取时间 + 快照索引 | ROE=18.5%, 毛利率=35.2%, 负债率=42.3%（来源：akshare stock_financial_abstract, symbol=600089，获取时间：2026-07-15） |
| **计算（Calculation）** | 13 项指标加权评分公式 + 分步计算 | 综合评分=Σ(指标得分×权重)= (15×0.15)+(10×0.10)+...+(8×0.05)=6.18/10 |
| **结论（Conclusion）** | 5 级信号 + 置信度 + 原因 | 买入信号（6.18 处于 6.0~7.5），置信度：中，原因：8/13 指标达标但营收增速(5.2%)低于阈值(>10%) |

**输出规范：**
- 每条大师信号紧跟前置的推导链，格式：`[证据] 数据 → [计算] 评分 → [结论] 信号（置信度：X，原因：Y）`
- 禁止出现无数据支撑的"裸信号"
- 来源标注四要素：来源 + 获取时间 + 口径/定义 + 关键假设
- 数据若来自 API 抓取，存 provenance 快照并在证据段引用 `provenance/<id>.json @ [s,e]`
- 违反本模板（缺段/缺来源/缺计算步骤）视为 P0 缺陷，由 `adversarial-auditor` 拦截

## 核心心智模型

#### 模型1: 定量评分 + 大模型人格化的双轨制
**一句话**：先让代码客观计算财务指标并评分，再将评分结果以提示词形式输入大模型，让大模型模仿投资大师的思维方式做主观判断。
**证据**：
- 巴菲特Agent先计算ROE、债务权益比、营业利润率等13项指标（满分20分），再以提示词形式输入大模型
- 大模型提示词包含角色设定、核心投资理念、能力圈偏好、投资标准层级、语言风格、置信度等级
- 相比直接给大模型原始财报，预处理评分能显著降低计算难度、提高准确性
**应用**：构建任何需要"专家思维+数据驱动"的智能体时，都可以采用"代码定量→大模型定性"的双轨架构。
**局限**：定量指标的阈值设定具有主观性；大模型可能产生幻觉，需严格约束输出格式。

#### 模型2: 投资大师的能力圈映射
**一句话**：每位大师的投资理念不是通用模板，而是有明确的能力圈边界、优先级排序和语言风格。
**证据**：
- 巴菲特提示词明确限定能力圈偏好/回避行业，投资标准层级：能力圈→企业质量→管理层→财务→估值
- 彼得·林奇关注PEG比率、"ten-bagger"潜力、可理解成长股
- 格雷厄姆聚焦安全边际计算、格雷厄姆估值模型
- 费雪重视管理质量、研发投入、利润率稳定性
**应用**：设计投资大师Agent时，提示词必须包含：角色设定、核心投资理念、能力圈边界、投资标准层级、语言风格模仿。
**局限**：能力圈偏好需要针对A股市场重新校准；部分大师的抽象理念难以用单一财务指标刻画。

#### 模型3: 多分析师信号聚合与冲突处理
**一句话**：当多个分析师（包括不同风格的大师）给出矛盾信号时，投资组合管理Agent需要像真正的基金经理一样综合权衡。
**证据**：
- 投资组合管理Agent的提示词包含：所有分析师信号、最大交易数量、现金余额、当前仓位、股价、保证金水平
- 可采取行为：买入、卖出、做空、平仓、持有（A股改进版禁止做空）
- 输出严格JSON格式：股票代码、交易方向、数量、置信度、理由
- 测试案例：技术分析中性(0%) + 巴菲特看涨(75%) → 综合决策买入
**应用**：设计任何需要多源信息聚合的决策系统时，都可以用"并行分析→信号汇总→综合决策"的三层架构。
**局限**：信号冲突时的权重分配规则未明确公开；投资组合管理Agent的决策逻辑黑箱化，可解释性不足。

#### 模型4: 情感分析的LLM化升级
**一句话**：用LLM直接对新闻文本进行情感分类，替代简单的关键词匹配，大幅提升情感分析准确度。
**证据**：
- 原版仅通过统计"利好""利空"关键词数量判定情感，精确度差
- 改进版直接利用大模型文本分析能力，对新闻进行利好/利空/中性三分类
- 内部交易(30%) + 新闻情绪(70%)的权重结构保留
- 不同大师Agent可选用不同的情感判断标准
**应用**：任何需要文本情感分析的场景，都可以用大模型替代传统NLP方法。
**局限**：大模型情感判断存在随机性；新闻来源质量和时效性影响结果；缺乏情感强度的连续度量。

## 决策启发式

1. **代码算指标，大模型做判断**
   - 应用场景：构建投资大师Agent的技术路径
   - 案例：巴菲特Agent中，Python代码计算ROE、毛利率、负债率等13项指标并评分 → 评分结果写入提示词 → DeepSeek模仿巴菲特风格输出诊断

2. **提示词 = 角色 + 理念 + 能力圈 + 层级 + 风格 + 数据**
   - 应用场景：设计任何专家型Agent的提示词工程
   - 案例：巴菲特Agent提示词包含6层结构：角色设定(巴菲特)、7大核心投资理念、能力圈偏好/回避、5级投资标准优先级、语言风格模仿、定量评分数据集

3. **单股诊断用大师，组合构建用回测**
   - 应用场景：区分产品的两种使用模式
   - 案例：单只股票可选1个或多个大师Agent诊断；构建组合时选单一大师Agent（如彼得·林奇），对沪深300全量打分，选"看涨"股票等权构建组合，年度调仓

4. **情感分析LLM化，研报信息结构化**
   - 应用场景：提升智能体信息输入质量
   - 案例：新闻情感从关键词匹配升级为大模型三分类；为巴菲特/费雪Agent新增研报分析功能，从研报提取5类结构化信息（市场地位、管理层诚信、估值看法、长期机会、定价能力）

5. **风控要客观，决策可主观**
   - 应用场景：区分智能体中哪些环节用大模型、哪些不用
   - 案例：风险管理Agent纯客观数据计算（仓位上限20%）；投资组合管理Agent用大模型综合判断；基础分析师不用大模型；大师Agent用大模型

## 参数建议

### AkShare 调用参数

```python
# 获取实时行情
import akshare as ak
spot = ak.stock_zh_a_spot_em()  # 全部A股实时行情

# 获取历史K线（日线）
hist = ak.stock_zh_a_hist(symbol="000xxx", period="daily", adjust="qfq")

# 获取财务指标（按报告期）
fin = ak.stock_financial_abstract(stock="000xxx", indicator="按报告期")

# ⚠️ 已弃用函数：stock_zh_index_hist_em（改用 stock_zh_index_daily_em）
```

### AI 调用参数

| 参数 | 建议值 | 说明 |
|------|--------|------|
| temperature | 0.1~0.3 | 金融分析需要高确定性，低 temperature |
| model | GPT-4o / Claude 3.5 Sonnet | 优先选择推理能力强的大模型 |
| max_tokens | 2000 | 评分输出不需要过长 |

## 常见错误案例

### 错误一：未先查持仓就下绝对结论
- ❌ "931994 与半导体没有关系"
- ✅ 先查成分股 → 确认股票暴露端关系 → 分维度表述

### 错误二：证据链不完整就下结论
- ❌ 只给结论，不给数据来源、具体数值、推导过程
- ✅ 用标准模板：结论（留有余地）+ 证据 + 推导 + 不确定性

### 错误三：混淆相关性与因果性
- ❌ 两个指标同时变动，就断言一个导致另一个
- ✅ 必须说明是"相关"还是"因果"，如无法确认因果关系，使用"可能相关""伴随发生"等表述
