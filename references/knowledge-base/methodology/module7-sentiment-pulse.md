## 框架概览！

本模块核心是对**特定个股/板块/市场整体**进行情绪扫描与量化评分，通过聚合新闻、社交媒体、资金流向等多源信号，生成-1（极度恐慌）到+1（极度贪婪）的情绪评分，为交易决策提供"情绪温度计"。

---

## 情绪扫描工作流！

```
触发（用户输入：股票代码/板块/市场）
   ↓
多源数据采集
   ├─ 新闻：财经媒体/券商研报/公司公告
   ├─ 社交：雪球/股吧/微博（A股）；Twitter/Reddit（美股）
   ├─ 资金：北向资金/融资余额/龙虎榜（A股）
   └─ 衍生品：期权Put/Call比/VIX（美股）
   ↓
情绪评分（-1.0 到 +1.0）
   ↓
输出：情绪快照 + 关键叙事驱动 + 交易启示
```

## 情绪评分模型！

#### 模型1：情绪极端值作为逆向指标！
**一句话**：当情绪达到极端值（极度恐慌或极度贪婪）时，往往对应市场的局部顶部或底部，适合逆向布局。
**证据**：
- 极度恐慌（情绪评分 < -0.6）：市场超卖，恐慌性抛售，往往是买入窗口
- 极度贪婪（情绪评分 > +0.6）：市场超买，FOMO情绪主导，往往是减仓窗口
- 关键：必须等待"情绪极值 + 基本面/政策信号确认"再行动，单纯逆向可能过早
**应用**：将情绪评分纳入择时系统，情绪极值区域降低操作频率，等待确认信号。
**局限**：情绪极值可能持续较长时间（如2015年杠杆牛市，贪婪持续数月），单纯看情绪评分可能过早逆向导致亏损。

#### 模型2：新闻情绪与资金情绪的背离信号！
**一句话**：当新闻情绪（媒体叙事）与资金情绪（真金白银）背离时，优先相信资金情绪，因为资金不会撒谎。
**证据**：
- 案例：新闻全面看多（情绪评分+0.5），但北向资金连续净流出（资金情绪-0.3）→ 媒体叙事可能是"诱多"，真实情绪偏空
- 案例：新闻全面看空（情绪评分-0.4），但北向资金悄悄净流入（资金情绪+0.2）→ 媒体恐慌过度，可能是买入窗口
- 背离信号的操作价值高于单一信号
**应用**：每日监控情绪时，必须同时给出新闻情绪和资金情绪，标注是否背离。
**局限**：资金情绪也有误导性（如北向资金中有"假外资"），需要结合多个资金指标交叉验证。

#### 模型3：社交媒体情绪的噪音过滤！
**一句话**：社交媒体（雪球/股吧/微博）情绪是散户情绪的集中体现，噪音极大，必须经过清洗才能使用。
**证据**：
- 噪音来源：机器人账号、付费推广、情绪化表达（涨了吹、跌了骂）
- 清洗方法：
  1. 剔除粉丝数<100的账号（可能是机器人）
  2. 剔除24小时内发布>50条的账号（ spam）
  3. 对剩余内容进行AI情感分析（利好/利空/中性）
  4. 计算情绪得分时，给认证账号（大V/机构）更高权重
- 清洗后社交媒体情绪权重降至20%（原版可能高达50%）
**应用**：任何使用社交媒体数据的情绪分析系统，都必须设计噪音过滤机制。
**局限**：过度过滤可能丢失"聪明钱"在社交媒体的提前布局信号（如某些大V在正式研报发布前在雪球发声）。

#### 模型4：板块情绪轮动的先行指标！
**一句话**：板块情绪的变化往往领先于板块价格的变动，监控板块情绪轮动可以提前布局。
**证据**：
- 观察对象：各板块的涨停家数、北向资金分板块净流入、券商研报覆盖数量变化
- 案例：AI板块情绪升温 → 涨停家数从5只增至30只 + 北向资金大幅流入AI龙头 → 1-3天后AI板块指数突破
- 案例：新能源板块情绪降温 → 研报覆盖数量减少 + 北向资金流出 → 1-3天后新能源板块指数回调
- 应用：每日记录各板块情绪得分，发现情绪升温的板块提前布局
**局限**：板块情绪轮动受政策催化影响极大（如突然发布的产业扶持政策），纯情绪指标可能无法捕捉政策冲击。

## 决策启发式！

1. **情绪评分+趋势方向，两者结合才有操作价值**
   - 应用场景：任何基于情绪的交易决策
   - 案例：情绪评分-0.5（恐慌）+ 趋势向下 → 观望，不抄底；情绪评分-0.5 + 趋势企稳 → 可小仓位逆向布局！

2. **北向资金连续3天同向流动，确认情绪方向**
   - 应用场景：判断外资情绪的真实方向
   - 案例：北向资金连续3天净流入 > 50亿/天 → 外资情绪真实偏多 → 可跟随；单日净流入可能是偶然！

3. **新闻看多但龙虎榜机构出货，警惕诱多**
   - 应用场景：识别媒体叙事与机构行为的背离
   - 案例：新闻全面看多AI板块 + 龙虎榜显示机构席位净卖出 → 可能是媒体"诱多" + 机构借机出货 → 减仓或观望！

4. **情绪极值区域，等待确认信号再逆向操作**
   - 应用场景：市场极度恐慌或极度贪婪时
   - 案例：情绪评分-0.7（极度恐慌）+ VIX>30 + 北向资金开始净流入 → 三个信号共同确认 → 可逆向建仓；仅有情绪评分不满足！

5. **社交媒体情绪仅作参考，不参与评分核心权重**
   - 应用场景：设计情绪评分模型时的权重分配
   - 案例：社交媒体情绪权重20%（噪音大），北向资金权重25%（真金白银），新闻情绪30%（叙事方向）！

### 推导链强制模板（P0·可审计，v3.1.0 新增）

**所有情绪结论必须按以下三段式呈现：**

| 段 | 必须包含 | 示例 |
|------|---------|------|
| **证据（Evidence）** | 各源信号分项 + 来源 + 获取时间 | 新闻情绪+0.4（利好叙事>60%），资金情绪+0.3（北向净流入52亿/融资余额平稳），社交情绪+0.2（雪球讨论偏积极）（来源：东方财富/雪球，获取时间：2026-07-15 15:30） |
| **计算（Calculation）** | 情绪评分 = Σ(各源得分×权重) + 趋势判断 | 综合评分=(0.4×0.30)+(0.3×0.25)+(0.2×0.20)=0.23；趋势：1周前-0.1→3天前+0.2→今日+0.23，持续回暖但未达贪婪(+0.6) |
| **结论（Conclusion）** | 情绪等级 + 操作建议 + 置信度 | 偏多（评分 0.23，处于 -0.2~+0.6），可持有或小幅加仓；止损参考：跌破-0.2。置信度：中，原因：新闻/资金/社交三者方向一致，无背离信号 |

**输出规范：**
- 情绪评分必须附各源分项（新闻/资金/社交），不得仅给综合评分
- 若出现背离信号（新闻 vs 资金差 > 0.5），必须在结论段标注"优先相信资金情绪"
- 来源四要素 + provenance 快照索引（新闻类抓取即存快照）
- 违反本模板视为 P0 缺陷

## 背离信号识别规则！

| 背离类型 | 识别方法 | 操作建议 |
|----------|----------|----------|
| 新闻 vs 资金背离 | 新闻情绪与资金情绪差 > 0.5 | 优先相信资金情绪 |
| 价格 vs 资金背离 | 价格上涨但资金净流出 | 警惕假突破 |
| 价格 vs 情绪背离 | 价格下跌但情绪极度乐观 | 警惕诱多 |
