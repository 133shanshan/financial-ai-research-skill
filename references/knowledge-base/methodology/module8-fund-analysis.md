## 一、心智模型（Mental Models）

### 1.1 核心思维框架

**四维分析框架**：
- **基金经理维度**：投资能力、风格稳定性、经验适应性
- **基金产品维度**：业绩表现、风险控制、费用成本
- **持仓组合维度**：资产配置、行业偏好、个股选择能力
- **市场环境维度**：适配性分析、周期轮动、风险提示

**关键认知**：
- 过往业绩不代表未来收益，但能反映基金经理的投资能力
- 费用率对长期收益的侵蚀效应（复利视角）
- 规模是业绩的敌人（规模过大导致调仓困难、冲击成本高）
- 风格漂移是主动管理基金的最大风险

### 1.2 分析边界

**必须分析的内容**：
- 基金经理背景、投资理念、历史业绩
- 基金风险收益指标（夏普、 Sortino、最大回撤、波动率）
- 持仓结构（前十大重仓、行业配置、换手率）
- 与业绩基准的比较（跟踪误差、信息比率）
- 费用结构（管理费、托管费、申购赎回费）

**可选分析内容**：
- 基金公司整体实力（投研团队、风控体系）
- 相似基金对比（同类型排名、差异化优势）
- 投资建议（适合人群、配置建议、风险提示）

**不予分析的内容**：
- 预测未来净值走势（禁止预测）
- 承诺收益或保本（合规要求）
- 推荐具体买卖时点（仅提供分析，不提供投资建议）

## 二、决策启发式（Decision Heuristics）

### 2.1 基金经理评估启发式

**经验法则**：
- 从业年限 ≥ 5年，经历过完整牛熊周期 → 优先推荐
- 管理规模急剧扩张（3个月内翻倍）→ 警惕业绩稀释
- 投资理念清晰且长期坚守 → 风格稳定，值得信赖
- 频繁更换基金经理（2年内换3次以上）→ 回避

**快速判断信号**：
- 金牛奖获奖记录 → 行业认可度高
- 北向资金重仓持股 → 与国际投资理念契合
- 高换手率（>300%）→ 可能是交易型选手，需关注交易成本

### 2.2 基金业绩评估启发式

**核心指标优先级**：
1. **夏普比率**（风险调整后收益）→ 最重要
2. **最大回撤**（极端风险控制）→ 第二重要
3. **信息比率**（相对基准的超额收益稳定性）→ 第三重要
4. **年化收益**（绝对收益）→ 第四重要

**评估标准**（主动股票型基金）：
- 夏普比率 > 1.0 → 优秀
- 夏普比率 0.5-1.0 → 良好
- 夏普比率 < 0.5 → 需谨慎

- 最大回撤 < 20%（牛市中）< 30%（熊市中）→ 风控优秀
- 最大回撤 > 50% → 高风险，需结合市场环境判断

### 2.3 持仓分析启发式

**集中度风险**：
- 前十大重仓股占比 > 60% → 高风险高收益
- 前十大重仓股占比 < 40% → 分散投资，相对稳健

**行业配置**：
- 单一行业占比 > 30% → 行业主题基金特征
- 行业配置过于集中 → 需评估行业前景和估值

**换手率**：
- 年化换手率 < 100% → 买入持有策略
- 年化换手率 100%-300% → 正常调仓
- 年化换手率 > 300% → 频繁交易，关注交易成本

### 推导链强制模板（P0·可审计，v3.1.0 新增）

**所有基金分析结论必须按以下三段式呈现：**

| 段 | 必须包含 | 示例 |
|------|---------|------|
| **证据（Evidence）** | 关键指标数值 + 来源 + 获取时间 + 快照索引 | 近3年年化收益 12.5%, 夏普 1.25, 最大回撤 -28.5%, 管理费 1.50%/年（来源：AkShare fund_open_fund_info_em, symbol=005827，获取时间：2026-07-15 14:30） |
| **计算（Calculation）** | 指标计算公式 + 分步结果 | 夏普=(12.5%-3.0%)/10.2%=0.93；总成本3年=管理费(1.50%×3)+申购费1.50%+赎回费0.50%=6.50%，分摊约 2.17%/年 |
| **结论（Conclusion）** | 适合人群 + 配置建议 + 风险提示 + 置信度 | 适合稳健型及以上、3年以上持有；建议仓位 20-40%。置信度：高（数据完整、经理稳定），风险：规模 180.5 亿较大需关注业绩稀释 |

**输出规范：**
- 每个关键结论（业绩/经理/持仓/费用）必须有一条独立的推导链
- 禁止"夏普优秀"不附夏普数值和计算口径
- 来源四要素 + provenance 快照索引（净值/持仓数据抓取即存快照）
- 违反本模板视为 P0 缺陷

AI执行：

## 四、HITL 节点（Human-in-the-Loop）

### 4.1 必须暂停确认的节点

**HITL 节点 1：分析框架确认**
```
触发条件：
- 用户需求模糊（如"帮我分析一下基金"）
- 需要分析多只基金并进行对比

AI行为：
暂停执行，向用户确认：
1. 需要分析的基金代码或名称
2. 分析重点（业绩/持仓/经理/费用）
3. 是否需要对比分析

等待用户确认后，再继续执行。
```

**HITL 节点 2：边界案例判断**
```
触发条件：
- 基金成立时间 < 1年，历史数据不足
- 基金经理管理该基金时间 < 1年
- 基金近期出现大额赎回（规模缩水 > 50%）

AI行为：
暂停执行，向用户提示：
"该基金数据可能存在偏差，原因如下：
- [具体原因]
是否继续分析？或建议更换为同类基金？"

等待用户确认后，再继续执行。
```

**HITL 节点 3：高风险警示**
```
触发条件：
- 基金最大回撤 > 50%
- 基金近期业绩大幅下滑（近3个月排名后10%）
- 基金经理变更（近6个月内）

AI行为：
在报告中突出显示风险提示，并向用户确认：
"该基金存在以下风险：
- [具体风险点]
是否在报告中加入风险警示章节？"

等待用户确认后，再生成最终报告。
```

### 4.2 可选建议节点

**建议节点 1：数据分析建议**
```
触发条件：
- AkShare 数据获取失败（网络超时、API限流）
- 数据缺失（某个季度持仓数据未披露）

AI行为：
不暂停，但记录到 Gotchas 部分，并在报告中标注：
"部分数据缺失，分析结论可能存在偏差"
```

**建议节点 2：报告格式建议**
```
触发条件：
- 用户未明确指定输出格式

AI行为：
默认生成 .docx 报告，但向用户确认：
"将生成 Word 报告，是否需要调整格式或增加特定章节？"

如果用户未回应，则按默认格式生成。
```

## 六、常见错误案例（Common Errors）

### 6.1 数据获取错误

**错误案例 1：基金代码格式错误**
```
错误行为：
fund_info = ak.fund_individual_basic_info_xq(symbol="005827.OF")

正确行为：
fund_info = ak.fund_individual_basic_info_xq(symbol="005827")
# AkShare 基金代码不需要后缀，直接传6位数字
```

**错误案例 2：净值数据时间范围不足**
```
错误行为：
# 只获取近1年数据
fund_nav = ak.fund_open_fund_info_em(symbol="005827", indicator="单位净值走势")
# 默认返回近1年数据，不足以评估完整周期表现

正确行为：
# 获取近3年或成立以来数据
# 注意：AkShare 可能需要分页获取或指定起始日期
start_date = "20230518"  # 3年前
end_date = "20260518"
fund_nav = ak.fund_open_fund_info_em(symbol="005827", indicator="单位净值走势", 
                                      start_date=start_date, end_date=end_date)
```

### 6.2 指标计算错误

**错误案例 3：夏普比率计算错误**
```
错误行为：
# 使用日收益率计算夏普比率，但未年化
daily_sharpe = (daily_return - risk_free_rate) / daily_volatility
# 错误：未乘以 sqrt(252)

正确行为：
# 方法1：先计算年化收益和年化波动，再计算夏普比率
annual_return = (nav_end / nav_start) ** (252 / trading_days) - 1
annual_volatility = daily_volatility * np.sqrt(252)
sharpe_ratio = (annual_return - risk_free_rate) / annual_volatility

# 方法2：直接使用日数据计算，然后年化
daily_excess_return = daily_return - risk_free_rate / 252
sharpe_ratio = daily_excess_return.mean() / daily_excess_return.std() * np.sqrt(252)
```

**错误案例 4：最大回撤计算错误**
```
错误行为：
# 使用错误的方法计算回撤
drawdown = (nav - nav.mean()) / nav.mean()
# 错误：回撤应该是 (当前净值 - 历史最高净值) / 历史最高净值

正确行为：
cummax = nav.cummax()
drawdown = (nav - cummax) / cummax
max_drawdown = drawdown.min()
# 注意：结果是负数，如 -0.25 表示最大回撤 25%
```

### 6.3 分析逻辑错误

**错误案例 5：忽略基金经理变更影响**
```
错误行为：
# 直接分析基金近3年业绩，未考虑基金经理变更
# 导致将前任经理的业绩算到现任经理头上

正确行为：
# 先检查基金经理变更历史
manager_history = ak.fund_manager_change_em(symbol="005827")
# 如果近期有变更，分段分析不同经理的业绩
# 或在报告中明确标注："自YYYY-MM-DD起由当前经理管理"
```

**错误案例 6：风格漂移未识别**
```
错误行为：
# 仅根据基金名称判断风格（如"大盘蓝筹"），未根据实际持仓验证

正确行为：
# 分析实际持仓的风格特征
# 1. 计算持仓股票的平均市值（大盘/中盘/小盘）
# 2. 计算持仓股票的价值/成长指标（PE、PB、PEG）
# 3. 如果发现实际持仓与名义风格不符，在报告中提示"风格漂移风险"
```
