## 核心心智模型

#### 模型1：Risk-On/Risk-Off 的资产轮动逻辑
**一句话**：全球风险情绪是决定短期资产价格方向的核心变量，VIX是观察风险情绪的最佳单一指标。
**证据**：
- Risk-On：VIX < 15 + S&P 500创新高 + 美债收益率上行 + 美元走弱 + 大宗商品涨
- Risk-Off：VIX > 25 + S&P 500破位 + 美债收益率下行 + 美元走强 + 黄金涨（避险）
- A股映射：Risk-On → 北向资金净流入 + 成长股/消费股占优；Risk-Off → 北向净流出 + 红利/防守股占优
**应用**：每日盘前先判断全球Risk-On/Off状态，再决定A股仓位方向和风格偏好。
**局限**：VIX仅反映美股预期波动率，对A股的直接影响存在时滞；且Risk-On/Off是结果而非原因，需要结合基本面判断可持续性。

#### 模型2：美债收益率曲线与资产价格的领先关系
**一句话**：美债收益率是全球资产定价的锚，10年期美债收益率的方向比绝对水平更重要。
**证据**：
- 10年期美债收益率 ↑ → 全球无风险利率 ↑ → 成长股估值承压（DCF分母变大）
- 10年期美债收益率 ↓ → 全球无风险利率 ↓ → 成长股估值扩张
- 2年期-10年期利差（收益率曲线）：倒挂（2年>10年）= 衰退预期；陡峭化 = 复苏预期
- A股映射：美债收益率上行 → 纳斯达克承压 → A股科技股跟跌；美债收益率下行 → 全球成长股共振上涨
**应用**：判断A股科技/新能源等长久期资产的走势，必须先看美债收益率方向。
**局限**：中美利差倒挂（美债收益率 > 中债收益率）时，资本外流压力加大，A股逻辑可能偏离美债单一变量。

#### 模型3：板块轮动的周期驱动框架
**一句话**：板块轮动不是随机的，而是由**经济周期位置**和**利率周期位置**共同驱动的。
**证据**：
- 复苏期：消费/科技领涨（利率低 + 盈利改善预期）
- 过热期：周期/能源领涨（通胀上行 + 大宗商品涨价）
- 滞胀期：红利/防守领涨（增长停滞 + 通胀高企）
- 衰退期：债券/现金占优（降息预期 + 风险资产承压）
- A股特色：政策周期是第六个维度（中国特有的"政策底→市场底→经济底"传导）
**应用**：判断当前处于哪个周期阶段，再决定板块配置权重。
**局限**：现实中的周期阶段划分存在模糊地带，且政策干预可能改变周期的自然演化路径。

#### 模型4：VIX作为逆向指标的反转信号
**一句话**：VIX极高（>35）往往是市场恐慌见底的逆向买入信号；VIX极低（<12）往往是市场自满的警示信号。
**证据**：
- 历史案例：2020年3月COVID崩盘，VIX最高飙升至85，随后S&P 500见底反弹
- 历史案例：2017年全年VIX < 12，市场自满，2018年2月VIX突然飙升至50，引发波动率危机
- A股映射：iVIX极高 → 恐慌见底 → 可逐步建仓；iVIX极低 → 市场自满 → 需警惕回调
**应用**：将VIX作为逆向指标纳入择时系统，而非仅仅作为"风险因素"。
**局限**：VIX尖峰往往对应政策干预窗口（美联储/央行出手），单纯逆向操作可能错过政策信号的确认。

## 决策启发式

1. **盘前先看VIX和美股，再判断A股开盘方向**
   - 应用场景：每日9:00-9:30 盘前准备
   - 案例：隔夜美股S&P 500跌>1% + VIX飙升至25+ → A股大概率低开 → 观察北向资金开盘方向再决定操作

2. **美债收益率方向比绝对水平更重要**
   - 应用场景：判断成长股/科技股走势
   - 案例：10年期美债收益率从4.5%降至4.2%（下行趋势）→ 成长股估值扩张 → A股科技股受益

3. **北向资金连续3天净流出，警惕全球Risk-Off**
   - 应用场景：A股特色风险预警
   - 案例：北向资金连续净流出 + 融资余额下降 → 内外资共振撤离 → 降低仓位或切换红利防守

4. **快速报告用情绪快照，深度报告用完整框架**
   - 应用场景：区分每日盘前 vs 周度策略的报告深度
   - 案例：每日盘前 → 📊 Market Summary 快速版（VIX + 指数涨跌 + 关键事件 + 环境判断）；周度策略 → 完整版（6个部分 + 板块轮动 + 投资策略）

5. **经济日历按重要性分级，关键事件前减仓避险**
   - 应用场景：FOMC/CPI/NFP等关键数据发布前
   - 案例：FOMC决议前1天 → 降低仓位规避不确定性 → 决议落地后根据鹰鸽方向重新建仓

### 推导链强制模板（P0·可审计，v3.1.0 新增）

**所有市场环境判断必须按以下三段式呈现：**

| 段 | 必须包含 | 示例 |
|------|---------|------|
| **证据（Evidence）** | 关键指数/VIX/美债收益率 + 来源 + 获取时间 | S&P 500: 5,234.56 (-0.45%), VIX: 18.5, 10Y美债: 4.25%（来源：TradingView/FRED，获取时间：2026-07-15 17:00 GMT+8） |
| **计算（Calculation）** | Risk-On/Off 判断逻辑 + VIX 阈值比对 | VIX=18.5 处于 15~25 区间（正常），北向净流入 +52亿（Risk-On信号），美债收益率下行 5bp（成长股估值压力缓解）→ 综合判断 Risk-On 延续 |
| **结论（Conclusion）** | 环境标签 + 仓位/风格建议 + 置信度 | Risk-On 延续，建议仓位 60%，风格偏成长/科技，回避红利防守。置信度：中，原因：CPI 发布前市场谨慎，VIX 小幅上升但未突破 25 |

**输出规范：**
- 盘前快速版和深度版都必须有推导链（快速版可简化但不得省略证据段）
- 禁止"今天 Risk-On"不附 VIX/北向/美债数据
- 所有时间标注时区（参考 L162 强制规则）
- 来源四要素 + provenance 快照索引
- 违反本模板视为 P0 缺陷
