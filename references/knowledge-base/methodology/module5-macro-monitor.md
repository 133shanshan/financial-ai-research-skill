## 框架概览

本模块核心是实现**宏观数据的自动化监控与推送**，通过定时任务（cron）每日自动浏览免费数据源，采集过去24小时发布的宏观数据和政策信息，整理后推送给用户。每个指标必须附带通俗科普解释，降低理解门槛。

## 超预期判断规则

```
超预期 = |Actual - Expected| > 市场预期标准差 × 1.5
```

| 指标 | 市场预期来源 | 判断阈值 |
|------|--------------|----------|
| CPI | Wind 一致性预期 | |Actual - Expected| > 0.2% |
| PPI | Wind 一致性预期 | |Actual - Expected| > 0.3% |
| PMI | 财新/统计局预期 | PMI 变动 > 1.0 |
| 社融 | 财联社预期 | |Actual - Expected| > 5000亿元 |

## 核心心智模型

#### 模型1：指标科普的分层体系
**一句话**：不是所有用户都懂宏观指标，每个指标必须同时给出**数值**和**通俗解释**，才能真正产生投资参考价值。
**证据**：
- 强制规则：每个指标都必须添加 💡 科普解释，没有例外
- 科普来源优先级：先查 `references/indicators.md` → 找不到则多源搜索验证 → 整理后加入知识库
- 科普格式：`💡 [指标名]：[一句话定义] - 为什么重要：[简短说明] - 怎么看：[正常范围/关键阈值]`
**应用**：任何面向非专业用户的金融分析，都必须配套通俗解释，否则只是"数据搬运"。
**局限**：部分指标的"关键阈值"存在争议（如CPI多少算高通胀），需要注明是市场共识而非绝对标准。

#### 模型2：未知指标的多源验证流程
**一句话**：遇到知识库中没有的指标，必须通过**至少三个来源**交叉验证，才能写入科普解释，避免以讹传讹。
**证据**：
- 搜索1：`"[指标名] 是什么 意思"`
- 搜索2：`"[指标名] 经济指标 解释"`
- 搜索3：`"[指标名] trading economics"` 或 `"[指标名] investing.com"`
- 优先选择：央行官网 > 统计局 > 知名财经媒体 > 个人博客
- 对比多个来源的解释，确保准确性后再整理输出
**应用**：构建任何金融知识库时，未知条目的处理必须有标准化的验证流程。
**局限**：部分指标在不同国家/地区的定义略有差异（如美国的CPI vs 中国的CPI篮子权重不同），需要注明口径。

#### 模型3：超预期/不及预期的叙事构建
**一句话**：宏观数据对市场的影响不取决于**绝对值**，而取决于**实际值 vs 预期值**的差异方向和幅度。
**证据**：
- 超预期（Actual > Expected）：经济强势 → 利率上行预期 → 债券跌、股票涨（成长股可能承压）
- 低于预期（Actual < Expected）：经济走弱 → 宽松预期 → 债券涨、防守股占优
- 关键：必须同时给出 Actual / Expected / Previous 三个数值，才能判断市场反应方向
**应用**：在推送宏观数据时，始终以"预期差"为核心叙事框架，而非单纯罗列数值。
**局限**：市场预期往往在数据发布前已经被部分定价（price in），所以"超预期"不一定带来市场反应。

#### 模型4：时间过滤与重要性加权
**一句话**：不是所有宏观数据都值得推送，必须按**时间窗口**和**重要性等级**双重过滤。
**证据**：
- 时间过滤：仅采集过去24小时（GMT+8）发布的数据和新闻
- 重要性等级：
  - ⭐⭐⭐⭐⭐：FOMC、NFP（非农）、CPI、GDP、PMI（主要经济体）
  - ⭐⭐⭐⭐：PPI、零售销售、工业产值、央行利率决议
  - ⭐⭐⭐：贸易收支、房价指数、消费者信心
  - ⭐⭐：地区性数据、次要经济体数据
- 推送顺序：按重要性降序排列，高重要性数据优先展示
**应用**：任何数据监控系统的设计，都必须有重要性分级机制，避免信息过载。
**局限**：重要性分级是主观判断，不同投资风格对数据的关注重点不同（如债券交易员更关注CPI/PPI，股票交易员更关注GDP/零售销售）。

## 决策启发式

1. **先查知识库，再搜索，再整理**
   - 应用场景：处理未知宏观指标
   - 案例：遇到"核心PCE"不在知识库中 → 搜索"核心PCE 是什么"+"core PCE investing" → 对比3个来源 → 整理 💡 科普解释 → 可选：更新知识库

2. **实际值、预期值、前值，三者缺一不可**
   - 应用场景：任何宏观数据推送
   - 案例：CPI发布 2.5%，预期 2.4%，前值 2.3% → 超预期 0.1pp → 利率上行预期升温 → 债券跌、金融股受益

3. **高重要性数据必加市场影响解读**
   - 应用场景：FOMC/CPI/NFP/GDP等关键数据发布后
   - 案例：美国CPI超预期 → 💡 解读：通胀粘性 → 美联储降息预期推迟 → 美债收益率上行 → 美元走强 → A股外资流出压力

4. **国内数据重点看政策映射，国际数据重点看美联储反应**
   - 应用场景：区分国内外数据的分析重点
   - 案例：中国PMI低于预期 → 可能触发降准/降息预期 → 关注国南网/基建链；美国非农超预期 → 美联储鹰派预期升温 → 全球风险资产承压

5. **数据源不可用要有降级方案**
   - 应用场景：某个数据源访问失败时
   - 案例：Trading Economics 访问失败 → 降级到 FRED + 财联社 交叉验证 → 标注"部分数据源未获取到"避免信息不完整

### 推导链强制模板（P0·可审计，v3.1.0 新增）

**所有宏观数据解读结论必须按以下三段式呈现：**

| 段 | 必须包含 | 示例（定量数据） | 示例（定性政策·变体） |
|------|---------|------|------|
| **证据（Evidence）** | Actual/Expected/Previous 三元组 + 来源 + 获取时间 | 美国CPI: Actual=2.5% / Expected=2.4% / Previous=2.3%（来源：Trading Economics，获取时间：2026-07-15 08:00 GMT+8） | 央行 MLF 操作利率由 2.50% 下调至 2.30%（来源：央行官网 pbc.gov.cn，获取时间：2026-07-15） |
| **计算（Calculation）** | 超预期公式 / 逻辑链 | \|2.5%-2.4%\|=0.1% < 阈值 0.2%，未显著超预期；但连续 2 个月上行(2.3→2.4→2.5)，趋势需关注 | MLF 下调→银行负债成本降低→LPR 有望跟随→实体融资成本下行→利好权益资产估值扩张（逻辑链） |
| **结论（Conclusion）** | 市场影响 + 受益/承压板块 + 置信度 | 中性偏鹰，A股短期承压有限；受益：金融（利差扩大）；承压：成长股（高估值敏感）。置信度：中 | 利好 A 股，延续宽松周期。受益：地产/基建（融资成本降）、成长（估值扩张）。置信度：高 |

**输出规范：**
- 定量数据走完整三段链（证据→计算→结论）；定性政策走变体（证据→逻辑链→结论），但都必须有源有据
- 启发式 #2（"实际值、预期值、前值三者缺一不可"）已为推导链证据段的前提
- 禁止仅标注"超预期/不及预期"不附实际值/预期值
- 来源四要素 + 快照索引；定性政策类必须附带原通告链接
- 违反本模板视为 P0 缺陷

## A股影响映射（宏观→板块）

```
宏观信号 → 受益板块 → 逻辑链条

CPI下行/降准预期 → 成长股（科技/新能源）/ 地产链 → 融资成本下降
PPI上行 → 周期股（有色/煤炭/化工）/ 上游资源 → 涨价传导利润改善
PMI扩张 → 周期股/消费股 → 经济扩张→企业盈利改善
社融高增 → 金融股（银行/券商）/ 地产链 → 信用扩张→资产质量改善
美联储鹰派 → 美元强→新兴市场承压 → A股外资流出→权重股承压
美联储鸽派 → 美元弱→新兴市场受益 → A股外资流入→成长股涨
```

## AkShare 数据获取规范

### 标准调用模板

```python
import akshare as ak
import pandas as pd

# CPI（必须指定 format，否则日期解析失败）
cpi = ak.macro_china_cpi_monthly(symbol="全部", format="%Y年%m月份")

# PPI
ppi = ak.macro_china_ppi_monthly(symbol="全部", format="%Y年%m月份")

# PMI
pmi = ak.macro_china_pmi()

# 社融增量
she = ak.macro_china_shehui_rongzi()

# LPR
lpr = ak.macro_china_lpr()

# MLF
mlf = ak.macro_china_mlf()
```

### ⚠️ 强制规则

1. **CPI/PPI/PMI 必须带 `format='%Y年%m月份'`**，否则日期列全为 NaT
2. **数据获取后必须立即标注来源和时间**
3. **异常值（>3σ）必须人工复核**

## 科普解释模板

每个指标输出时必须附带通俗解释（💡），模板：

```
💡 **[指标名称]** 是什么？
[一句话解释]
- 为什么重要：[1-2句话]
- 怎么看：[关键阈值]
- 对A股影响：[传导逻辑]
```

示例：
```
💡 **CPI（居民消费价格指数）** 是什么？
衡量一篮子消费品价格变动，反映通胀水平。
- 为什么重要：CPI 过低 → 通缩风险；CPI 过高 → 加息预期
- 怎么看：> 3% 为通胀预警；< 1% 为通缩预警
- 对A股影响：CPI 过低 → 宽松预期 → 利好成长股；CPI 过高 → 加息预期 → 利空高估值板块
```
