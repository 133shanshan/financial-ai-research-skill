# 方法论知识库 — 模块四：行业基本面研究

> LLM Wiki 模式：中间知识层，由 AI 和人工共同维护。
> 本文档沉淀模块四的六大分析框架、TAM/SAM/SOM 测算方法、常见行业数据。

## 框架概览

本模块源自 Market Research Agent 方法论，核心是为 A 股投研提供**结构化行业研究框架**，覆盖市场概览、竞争格局、客户分析、SWOT、波特五力、Go-to-Market 洞察六大维度，与模块一（选股）、模块二（政策）、模块三（资配）形成完整投研闭环。

```
行业基本面研究工作流：

数据获取（Wind/公司公告/行业研究报告）
    ↓
六大框架分析（市场/竞争/客户/SWOT/五力/Go-to-Market）
    ↓
投资启示提取（行业空间/竞争格局/产业链地位/催化剂）
    ↓
与模块一~三联动（选股信号/政策影响/资配权重）
```

## 六大研究框架

---

#### 框架1：市场概览（Market Overview）

**研究目标：** 明确行业定义、测算市场空间、识别核心趋势与驱动/制约因素。

| 分析维度 | 关键问题 | A股投研输出示例 |
|---------|---------|----------------|
| **市场定义** | 这个行业到底包含什么？边界在哪里？ | "电网设备行业：主营特高压/智能电网/配电设备，不含发电设备" |
| **市场规模** | TAM/SAM/SOM 各是多少？ | "TAM=电网总投资3万亿/年；SAM=设备采购约6000亿/年；SOM=上市龙头合计营收约2000亿/年" |
| **增长率** | 历史CAGR？未来3年预期CAGR？ | "2020-2025 CAGR=12%；预计2025-2028 CAGR=8-10%（新能源+AI用电驱动）" |
| **核心趋势** | 5-7个塑造行业的关键趋势 | "特高压建设加速/AI数据中心用电需求爆发/柔性直流技术渗透/IGBT国产化/电网数字化" |
| **驱动因素** | 什么在推动行业增长？ | "政策：十四五电网投资3万亿；需求：AI+新能源用电；技术：柔直/储能接入" |
| **制约因素** | 什么在限制行业增长？ | "铜/硅钢片成本占比高；特高压核准节奏不确定；地方保护导致价格竞争" |

**证据要求：**
```
市场规模数据必须注明来源：
- 官方来源：国家能源局/国家电网/南方电网公告 → 可信度最高
- 行业协会：中国电力企业联合会 → 可信度中高
- 券商研报：国信/国金/中信证券行业深度 → 需注明券商名称+报告日期
- 公司公告：上市公司招股书/年报/季报 → 可信度中（注意管理层口径偏乐观）
```

**常见错误：**
- ❌ "电网设备市场规模1万亿" → 未注明是TAM/SAM/SOM，未注明年份
- ✅ "电网设备（SAM，即A股上市公司可参与的设备采购市场）约6000亿/年（2024年，来源：国家电网2024年社会责任报告）"

#### 框架2：竞争格局（Competitive Landscape）

**研究目标：** 识别直接/间接竞品，用矩阵对比，找出市场空白点和取胜条件。

| 分析维度 | 关键问题 | A股投研输出示例 |
|---------|---------|----------------|
| **直接竞品** | 解决同一问题的上市公司有哪些？ | "特高压变压器：特变电工、中国西电、保变电气" |
| **间接竞品** | 替代性解决方案有哪些？ | "电网扩建（特高压）vs 分布式能源（光伏+储能）" |
| **竞品矩阵** | 按价格/功能/市场地位对比 | 见下方竞品矩阵表格 |
| **市场空白** | 哪些细分需求未被满足？ | "海上风电柔直送出设备，目前国产化率<30%" |
| **取胜条件** | 要成为龙头需要什么？ | "特高压：电压等级+运行业绩+客户关系；电网设备：成本控制+可靠性" |

**竞品矩阵模板（以电网设备为例）：**

| 公司 | 主营产品 | 市场地位 | 优势 | 劣势 | 2024营收(亿) | 毛利率 |
|------|---------|---------|------|------|------------|--------|
| 特变电工 | 变压器/特高压/新能源 | 龙头 | 全产业链/出海 | 负债率偏高 | ~980 | ~18% |
| 思源电气 | 开关/继电保护/储能 | 第二梯队 | 平台型/成长快 | 特高压份额低 | ~150 | ~28% |
| 国电南瑞 | 二次设备/电网自动化 | 细分龙头 | 技术壁垒高 | 成长放缓 | ~500 | ~35% |
| 亨通光电 | 电缆/海缆 | 细分龙头 | 海缆优势 | 业务多元分散 | ~520 | ~16% |

**证据要求：**
- 营收/毛利率数据：必须来自上市公司年报/季报（注明报告期）
- 市场地位判断：必须有市场份额数据或行业协会排名支撑
- 优劣势分析：区分"事实"（可验证）和"观点"（分析师判断）

#### 框架3：客户分析（Customer Analysis）

**研究目标：** 识别客户细分、理解客户痛点、分析购买决策逻辑。

> 注：A股行业研究中，"客户"可能是下游企业（To B）或终端消费者（To C），需根据行业特性调整。

| 分析维度 | 关键问题 | A股投研输出示例（电网设备，To B） |
|---------|---------|-----------------------------|
| **客户细分** | 谁在购买这个行业的产品？ | "国家电网（~60%）/南方电网（~20%）/地方电网（~10%）/海外（~10%）" |
| **买家画像** | 客户的核心特征是什么？ | "国家电网：价格敏感度低/质量敏感度极高/认证周期长（2-3年）/更换成本高" |
| **TOP5痛点** | 客户面临的最大问题是什么？ | "1.新能源接入导致电网不稳定 2.用电负荷增长超预期 3.设备老化需更换 4.碳达标压力 5.技术要求快速迭代" |
| **购买决策标准** | 客户如何评估供应商？ | "资质（入网许可证）>运行业绩（是否有同类项目）>价格>交付周期>售后服务" |
| **支付意愿** | 客户对价格的敏感度？ | "特高压：价格敏感度低（质量优先）；配网设备：价格敏感度高（招标竞价）" |

**对投资的含义：**
```
客户集中度分析 → 判断收入确定性
  - 特变电工：国南网占比高 → 收入确定性强，但议价能力弱
  - 思源电气：多行业布局 → 收入确定性稍弱，但成长弹性大

客户痛点 → 判断产品升级方向
  - 新能源接入不稳定 → 柔性直流设备需求增长 → 许继电气/国电南瑞受益
```

#### 框架4：SWOT分析（Strengths, Weaknesses, Opportunities, Threats）

**研究目标：** 结构化评估行业/公司的内外部因素。

**行业级SWOT模板（以电网设备行业为例）：**

| | 正面 | 负面 |
|---|------|------|
| **内部** | **优势（Strengths）** | **劣势（Weaknesses）** |
| | - 中国特高压技术全球领先<br>- 完整产业链（从硅钢到变压器）<br>- 国南网订单确定性强 | - 毛利率偏低（价格竞争）<br>- 应收账款周期长（2-3年）<br>- 技术迭代压力大（柔直/SiC） |
| **外部** | **机会（Opportunities）** | **威胁（Threats）** |
| | - AI数据中心用电需求爆发<br>- 特高压"十五五"规划预期<br>- 柔直/储能新需求<br>- 出海（一带一路）加速 | - 铜/硅钢片价格波动<br>- 地方保护导致区域壁垒<br>- 技术迭代快（IGBT/SiC）<br>- 政策节奏不确定（核准延期） |

**公司级SWOT（以特变电工为例）：**

| | 正面 | 负面 |
|---|------|------|
| **内部** | **优势**<br>- 变压器全球第一<br>- 新能源业务协同<br>- 出海经验丰富 | **劣势**<br>- 负债率偏高（~65%）<br>- 毛利率低于国电南瑞<br>- 海外业务汇率风险 |
| **外部** | **机会**<br>- 特高压新线核准<br>- 印度/东南亚电网建设<br>- 储能业务爆发 | **威胁**<br>- 中国西电/保变电气价格竞争<br>- 铜价上涨<br>- 海外地缘政治风险 |

**证据要求：**
- S/W（内部）：必须是可验证的事实（财报数据/产能数据/技术认证）
- O/T（外部）：必须注明信息来源（政策文件/行业报告/专家访谈）

#### 框架5：波特五力分析（Porter's Five Forces）

**研究目标：** 系统评估行业竞争格局和盈利能力。

| 力量 | 关键问题 | 电网设备行业示例 | 对投资的含义 |
|------|---------|----------------|-------------|
| **供应商议价力** | 上游是否能压榨行业利润？ | 硅钢片（新钢/武钢）集中度高中等；铜（全球定价）议价力强 | 特变电工等通过长期合约+期货对冲，但仍有成本波动风险 |
| **买家议价力** | 下游是否能压榨行业利润？ | 国南网双寡头，集采招标，议价力极强 | 行业毛利率天花板约30-35%，难突破 |
| **行业内竞争** | 现有竞争者之间是否激烈？ | 特高压：温和（资质壁垒高）；配网设备：激烈（价格战） | 投资优选特高压产业链，回避配网设备 |
| **替代品威胁** | 是否有颠覆性替代方案？ | 分布式新能源（减少远距离输电需求）| 长期威胁，但10年内特高压仍是主流 |
| **新进入者威胁** | 新玩家是否容易进入？ | 特高压：极难（资质+运行业绩+客户关系）；配网：容易 | 特高压龙头护城河深；配网设备护城河浅 |

**五力评分模板（1=最弱竞争压力，5=最强竞争压力）：**

| 力量 | 评分（1-5） | 说明 |
|------|------------|------|
| 供应商议价力 | 3 | 铜价波动有影响，但可控 |
| 买家议价力 | 5 | 国南网极强，行业利润被压缩 |
| 行业内竞争 | 2（特高压）/ 4（配网） | 分细分市场评估 |
| 替代品威胁 | 2 | 10年内影响有限 |
| 新进入者威胁 | 1（特高压）/ 4（配网） | 分细分市场评估 |
| **综合评分** | **相对温和（特高压）** / **激烈（配网）** | 投资应聚焦特高压产业链 |

#### 框架6：Go-to-Market洞察

**研究目标：** 理解行业如何触达客户、如何定价、关键合作方是谁。

| 分析维度 | 关键问题 | A股投研输出示例（电网设备） |
|---------|---------|----------------|
| **最佳获客渠道** | 如何触达客户？ | "国网/南网年度集采招标（最核心）；地方电网单独招标；海外通过EPC总包商" |
| **常见定价模式** | 如何收费？ | "招标竞价（价格权重30-50%）；成本加成定价；长期合约锁价" |
| **销售周期** | 从接触到交付要多长时间？ | "特高压：2-3年（资质认证→招标→交付→验收）；配网：6-12个月" |
| **关键合作伙伴** | 谁是重要的生态伙伴？ | "国网/南网（买家）；EPC总包商（出海渠道）；设计院（前期介入）" |

**对投资的含义：**
```
销售周期长 → 收入确认不均匀 → 季度业绩波动大 → 适合长期持有，不适合短线
关键合作伙伴稳定 → 先发优势明显 → 龙头份额持续提升 → 优选龙头
```

## TAM/SAM/SOM 测算方法

| 层级 | 定义 | 测算方法 |
|------|------|----------|
| TAM（全球潜在市场） | 全球所有潜在客户的总支出 | 自上而下：行业报告 + 渗透率假设 |
| SAM（中国可服务市场） | 中国地区可服务的市场 | 自上而下：TAM × 中国占比 |
| SOM（可获得市场份额） | 当前/未来可获得的份额 | 自下而上：龙头公司营收 ÷ SAM |

**示例：电网设备行业（2025E）**

| 层级 | 数值 | 测算依据 |
|------|------|----------|
| TAM | 800亿美元 | 全球电网投资总额（IEA 报告）|
| SAM | 320亿美元 | TAM × 中国占比 40%（IEA 中国能源展望）|
| SOM | 144亿美元 | 龙头 CR3 约 45%（国电南瑞+特变电工+许继电气）|

## 决策启发式

1. **市场规模先分TAM/SAM/SOM，再谈投资空间**
   - 应用场景：任何行业研究的第一步
   - 案例：电网设备TAM=3万亿（总投资），SAM=6000亿（设备采购），SOM=2000亿（上市公司营收）→ 行业已较成熟，增量看AI用电+出海

2. **竞品矩阵必须含营收/毛利率，否则无法判断竞争力**
   - 应用场景：选股前的行业扫描
   - 案例：国电南瑞毛利率35%（二次设备壁垒高）；特变电工18%（一次设备价格竞争）→ 不同细分赛道盈利能力差异大

3. **客户集中度高风险高，但确定性也高**
   - 应用场景：评估收入质量
   - 案例：国网南网占比>50% → 收入确定性强，但买家议价力强 → 毛利率天花板明显

4. **五力评分决定行业吸引力，不是所有行业都值得投**
   - 应用场景：行业筛选（模块三资配的输入）
   - 案例：特高压五力综合温和 → 适合配置；配网设备五力激烈 → 回避或仅选龙头

5. **SWOT的O/T必须标注时间窗口，否则无法判断催化剂时机**
   - 应用场景：判断买入/卖出时机
   - 案例："十五五规划2026年发布 → 特高压新线核准加速预期 → 2026H2可能是催化剂窗口"

### 推导链强制模板（P0·可审计，v3.1.0 新增）

**所有分析结论必须按以下三段式呈现，缺一不可：**

| 段 | 必须包含 | 示例（承接行业吸引力评分） |
|------|---------|------|
| **证据（Evidence）** | 关键市场数据 + 来源 + 获取时间 + 快照索引 | TAM=800亿美元（全球电网投资），SAM=320亿美元（中国占比40%），SOM=144亿美元（CR3约45%）（来源：IEA World Energy Outlook 2025，获取时间：2026-07-15） |
| **计算（Calculation）** | 行业吸引力评分 = Σ(维度得分×权重) 分步展示 | 评分=(市场规模8×0.20)+(五力综合3×0.30)+(增长前景9×0.25)+(催化剂7×0.15)+(政策环境8×0.10)=7.3/10 |
| **结论（Conclusion）** | 吸引力等级 + 配置建议 + 置信度 + 原因 | 有吸引力（7.3，处于 7.0~8.5），配置：适度配置，置信度：中，原因：TAM/SOM 来自 IEA（可信度高），增长强劲但买方议价力（国南网双寡头）约束毛利率 |

**输出规范：**
- 每条行业结论紧跟前置推导链：`[证据] 市场数据 → [计算] 吸引力评分 → [结论] 配置建议（置信度：X，原因：Y）`
- 证据段引用所使用框架（TAM/SAM/SOM、五力、SWOT 等）及数据来源
- 禁止只给"有吸引力"不附评分计算
- 来源标注四要素 + provenance 快照索引
- 违反本模板视为 P0 缺陷

## 与模块一~三的联动

```
模块四（行业基本面研究）
    ↓ 输出：行业吸引力评分、龙头公司列表、催化剂时间窗口
模块三（资配框架）
    ↓ 输入行业评分，调整权重
模块二（政策语义分析）
    ↓ 输入政策取向，判断行业政策催化力度
模块一（投资大师Agent）
    ↓ 输入龙头公司列表，生成买入/卖出信号
```

**完整投研工作流：**
```
1. 模块四：研究行业（市场/竞争/客户/SWOT/五力/GTM）
2. 模块三：根据行业吸引力，调整资配权重
3. 模块二：分析政策取向，判断流动性环境是否支持
4. 模块一：对行业龙头运行大师Agent诊断，生成交易信号
5. 风险管理：结合大师信号+资配权重，生成最终仓位
```

## A股行业研究速查表

| 行业类型 | 重点关注框架 | 核心指标 |
|---------|-------------|---------|
| **周期（电力/基建/化工）** | 市场概览（政策驱动）+ 五力（买家议价力）| 产能利用率、订单增速、毛利率趋势 |
| **成长（半导体/新能源/AI）** | 市场概览（TAM/SAM/SOM）+ SWOT（机会）| 营收增速、研发投入占比、市场份额变化 |
| **消费（食品/医药/零售）** | 客户分析（To C画像）+ 竞品矩阵（品牌力）| 复购率、客单价、品牌市占率 |
| **金融（银行/保险/券商）** | 五力（监管壁垒）+ 市场概览（利率周期）| NIM/ROE/PB估值 |
