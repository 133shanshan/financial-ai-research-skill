# 模块九：策略回测引擎

## 模块概述

**功能定位：** 对给定交易策略进行历史回测，输出性能指标和净值曲线，验证策略有效性。

**触发词：**
- "回测策略"、"策略回测"
- "看看这个策略历史表现"
- "模拟一下过去一年的收益"
- "backtest"、"策略验证"

## 回测框架

### 1. 数据获取

**数据源：** AkShare 历史行情数据

**关键API：**
```python
import akshare as ak

# 获取A股历史行情（日线）
```

### 2. 策略定义

**策略格式：** 用户可以用自然语言描述策略，AI解析为可执行规则。

**示例策略：**
```
策略名称：MA均线策略
买入条件：MA5 > MA20 且 MA20 向上
卖出条件：MA5 < MA20 且 MA20 向下
仓位管理：满仓买入/清仓卖出
止损线：-10%（回撤超过10%强制止损）
```

**AI解析流程：**
1. 读取用户自然语言策略描述
2. 解析为Python可执行函数
3. 生成策略代码（保存到 `scripts/strategies/` 目录）
4. 执行回测

### 3. 回测引擎

**核心逻辑：**
```python
# 伪代码
def run_backtest(strategy_func, df, initial_cash=1000000):
    cash = initial_cash  # 初始资金
    position = 0       # 持仓数量
    portfolio = []      # 每日资产组合
    
    for i, row in df.iterrows():
        signal = strategy_func(row, df[:i])  # 获取交易信号
        
        if signal == "BUY" and cash > 0:
            position = cash / row['收盘']  # 满仓买入
            cash = 0
        elif signal == "SELL" and position > 0:
            cash = position * row['收盘']   # 清仓卖出
            position = 0
        
        # 记录当日资产
        total = cash + position * row['收盘']
        portfolio.append(total)
    
    return portfolio
```

**交易规则：**
- **手续费：** 0.03%（双边）
- **印花税：** 0.1%（卖出）
- **滑点：** 0.2%（模拟真实交易）
- **仓位限制：** 最高95%（预留5%现金）

---

### 4. 性能指标

| 指标 | 计算公式 | 说明 |
|------|----------|------|
| **总收益率** | (期末资产-初始资金)/初始资金 | 策略绝对收益 |
| **年化收益率** | (1+总收益率)^(252/交易天数)-1 | 标准化年化收益 |
| **夏普比率** | (年化收益率-无风险利率)/年化波动率 | >1 较好，>2 优秀 |
| **最大回撤** | max((最高点-当前点)/最高点) | 越小越好 |
| **胜率** | 盈利次数/总交易次数 | >50% 较好 |
| **盈亏比** | 平均盈利/平均亏损 | >2 较好 |
| **索提诺比率** | (年化收益率-无风险利率)/下行波动率 | 只考虑下行风险 |
| **卡玛比率** | 年化收益率/最大回撤 | 回撤风险调整后收益 |

**基准对比：**
- 沪深300指数（000300.SH）
- 中证500指数（000905.SH）
- 策略 vs. 基准：超额收益、信息比率

## 执行流程

### Step 1：解析策略
- 读取用户输入的策略描述（自然语言）
- 解析为Python可执行函数
- 生成策略代码（保存到 `scripts/strategies/`）

### Step 2：获取历史数据
- 调用AkShare API获取历史行情
- 数据清洗（处理停牌、除权除息）
- 计算技术指标（MA、MACD、RSI、布林带等）

### Step 3：执行回测
- 按日期滚动执行策略
- 记录每日持仓和收益
- 生成净值曲线

### Step 4：计算性能指标
- 计算夏普比率、最大回撤、胜率等
- 对比基准指数表现
- 生成超额收益分析

### Step 5：生成报告
- 用python-docx生成.docx报告
- 插入净值曲线图（matplotlib生成）
- 插入回撤曲线图
- 插入交易明细表

### Step 6：HITL节点
- 展示核心结论（总收益率、夏普比率、最大回撤）
- 询问用户是否满意，是否需要调整参数重新回测
- 用户确认后交付报告

## 常见错误案例

### 错误1：未来函数
**错误代码：**
```python
# 错误：用未来数据计算买入信号
def strategy(row, history):
    if row['收盘'] < history['收盘'].min():  # 用了未来数据！
        return "BUY"
```

**正确做法：**
```python
# 正确：只用历史数据
def strategy(row, history):
    if len(history) < 20:
        return "HOLD"
    ma20 = history['收盘'].tail(20).mean()
    if row['收盘'] > ma20:
        return "BUY"
```

### 错误2：幸存者偏差
**问题：** 只回测当前存在的股票，忽略了已退市的股票。

**正确做法：**
- 使用全样本数据（包含已退市股票）
- 在回测区间内，如果股票退市，按最后交易日清仓处理

### 错误3：过拟合
**问题：** 策略参数过度优化，在历史数据上表现很好，但未来表现很差。

**正确做法：**
- 使用样本外测试（训练集/测试集拆分）
- 参数敏感性分析（参数微小变化是否导致性能大幅下降）
- 使用 Walk-Forward 分析（滚动窗口回测）

### 推导链强制模板（P0·可审计，v3.1.0 新增）

**所有回测结论必须按以下三段式呈现：**

| 段 | 必须包含 | 示例 |
|------|---------|------|
| **证据（Evidence）** | 回测参数 + 数据来源 + 获取时间 | 回测区间：2024-01-01~2026-07-15, 初始资金 100万, 手续费 0.03%双边+0.1%印花税, 滑点 0.2%, 数据前复权（来源：AkShare stock_zh_a_hist, symbol=600519，获取时间：2026-07-15） |
| **计算（Calculation）** | 核心指标公式 + 分步结果 | 年化收益率=(1+35.2%)^(252/620)-1=14.8%；夏普=(14.8%-3.0%)/10.3%=1.15；最大回撤=max(130-110)/130=-15.4% |
| **结论（Conclusion）** | 策略评级 + 是否跑赢基准 + 置信度 + 风险提示 | 良好（夏普 1.15 > 1.0），超额收益+22.7% vs 沪深300，胜率 52.3%。置信度：中，原因：2.5 年回测覆盖上涨+震荡周期，但未经历 2022 级熊市，需关注过拟合风险 |

**输出规范：**
- 报告「执行摘要」必须包含完整三段链，不得只列数字不列公式
- 报告「性能分析」的每个关键指标必须有计算步骤
- 来源四要素：数据源 + 获取时间 + 口径（前复权/后复权） + 假设（手续费/滑点/印花税规则）
- 违反本模板视为 P0 缺陷
