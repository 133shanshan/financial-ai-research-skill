# 每个指标包含：定义、重要性、关键阈值、对A股影响

## 国内宏观指标

### CPI（居民消费价格指数）
- **定义**：衡量一篮子消费品价格变化，反映通货膨胀水平
- **为什么重要**：决定央行货币政策取向（降息/加息），直接影响市场流动性
- **怎么看**：
  - < 1%：通缩风险，可能触发降准/降息
  - 1% - 3%：温和通胀，政策舒适区
  - > 3%：通胀压力，可能触发加息/收紧
  - 美联储目标：2%（美国CPI）
- **对A股影响**：
  - CPI下行 → 宽松预期 → 成长股/地产链受益
  - CPI上行 → 紧缩预期 → 金融/消费股受益
- **数据来源**：国家统计局，每月9-10日发布
- **AkShare函数**：`ak.macro_china_cpi()`
- **⚠️ 注意事项**：
  - 列名是`月份`（格式`2026年04月份`），不是`cpi`
  - 必须用`pd.to_datetime(df['月份'], format='%Y年%m月份')`解析
  - 否则`iloc[-1]`会取到错误行

---

### PPI（工业生产者出厂价格指数）
- **定义**：衡量工业品出厂价格变化，反映生产端通胀压力
- **为什么重要**：PPI向CPI传导（生产端→消费端），领先CPI 3-6个月
- **怎么看**：
  - > 0：生产端涨价，企业盈利改善
  - < 0：生产端降价，通缩压力，企业盈利承压
  - 负值区间关注拐点（由负转正通常是周期股启动信号）
- **对A股影响**：
  - PPI上行 → 周期股（有色/煤炭/化工）/上游资源受益
  - PPI下行 → 下游制造（毛利率改善）/成长股受益
- **数据来源**：国家统计局，每月9-10日发布
- **AkShare函数**：`ak.macro_china_ppi()`
- **⚠️ 注意事项**：
  - 列名是`月份`，不是`ppi`
  - 关键列：`当月同比增长`
  - 日期解析同CPI：`format='%Y年%m月份'`

---

### PMI（制造业采购经理人指数）
- **定义**：对制造业企业采购经理的月度调查，反映经济扩张/收缩
- **为什么重要**：经济景气的先行指标，通常领先GDP 1-3个月
- **怎么看**：
  - > 50：扩张（经济向好）
  - = 50：荣枯线（临界点）
  - < 50：收缩（经济下行）
  - 连续3个月 > 50：确认复苏
  - 连续3个月 < 50：确认衰退
- **分项指标**：
  - 生产指数：> 50 生产扩张
  - 新订单指数：> 50 需求改善
  - 原材料库存：> 50 补库存周期
- **对A股影响**：
  - PMI扩张 → 周期股/消费股受益
  - PMI收缩 → 红利/防守股受益
- **数据来源**：国家统计局，每月最后一天或次月1日发布
- **AkShare函数**：`ak.macro_china_pmi()`
- **⚠️ 注意事项**：
  - 列名是`月份`，不是`pmi`
  - 关键列：`制造业-指数`
  - 日期解析同CPI

---

### GDP（国内生产总值）
- **定义**：一国境内一定时期内生产的所有最终商品和服务的市场价值
- **为什么重要**：衡量经济总体增速，是政策制定和投资配置的核心参考
- **怎么看**：
  - 中国目标：~5%（2026年）
  - > 目标：经济过热，可能收紧
  - < 目标：经济下行压力，可能刺激
- **分产业看**：
  - 第一产业（农业）：通常稳定
  - 第二产业（工业）：受投资/出口影响大
  - 第三产业（服务业）：受消费影响大
- **对A股影响**：
  - GDP超预期 → 周期/消费股受益
  - GDP不及预期 → 政策刺激预期 → 基建/地产链受益
- **数据来源**：国家统计局，季度发布（1月/4月/7月/10月）
- **AkShare函数**：`ak.macro_china_gdp()`

---

### LPR（贷款市场报价利率）
- **定义**：商业银行对其最优质客户的贷款利率，是央行调控的基准利率
- **为什么重要**：直接影响企业融资成本和个人房贷利率
- **怎么看**：
  - 1年期LPR：影响企业短期融资成本
  - 5年期LPR：影响房贷和长期投资
  - 每次调降通常5-20bp（0.05%-0.20%）
- **调整频率**：每月20日（遇节假日顺延）
- **对A股影响**：
  - LPR下调 → 降低融资成本 → 成长股/地产/基建受益
  - LPR不变 → 政策观察期 → 市场关注下次调整窗口
- **数据来源**：央行官网，每月20日发布
- **AkShare函数**：`ak.macro_china_lpr()`
- **⚠️ 注意事项**：
  - 列名是`LPR1Y`和`LPR5Y`，不是`1年期`/`5年期`
  - `TRADE_DATE`列是日期

---

### MLF（中期借贷便利）
- **定义**：央行向商业银行提供中期基础货币的利率工具，是LPR的定价锚
- **为什么重要**：MLF利率下调通常领先LPR下调1-2周
- **怎么看**：
  - MLF下调 → 预期LPR跟进下调 → 降息周期开启
  - MLF不变 → LPR调整概率低
- **操作频率**：通常每月15日（遇节假日顺延）
- **对A股影响**：
  - MLF下调 → 宽松信号 → 全线风险资产上涨
  - MLF超量续作 → 流动性充裕 → 成长股受益
- **数据来源**：央行官网公告
- **AkShare函数**：需通过`ak.macro_china_mlf()`或WebSearch获取

---

### 社融增量（社会融资规模增量）
- **定义**：一定时期内实体经济从金融体系获得的资金总额
- **为什么重要**：反映金融体系对实体经济的支持力度
- **怎么看**：
  - 同比多增：信用扩张，经济活力增强
  - 同比少增：信用收缩，经济活力减弱
- **结构分析**：
  - 人民币贷款：主体，反映银行放贷意愿
  - 表外融资（信托/委托贷款）：反映监管松紧
  - 企业债券：反映直接融资活跃度
- **对A股影响**：
  - 社融高增 → 金融股（银行/券商）/地产链受益
  - 社融低迷 → 避险情绪 → 红利/国债受益
- **数据来源**：央行官网，每月10-15日发布
- **AkShare函数**：`ak.macro_china_social_finance()`（需确认函数名）

## 国际宏观指标

### 美国CPI（CPI US）
- **定义**：美国居民消费价格指数，美联储货币政策的核心参考
- **为什么重要**：决定美联储降息/加息节奏，直接影响全球资产定价
- **怎么看**：
  - > 2%：通胀高于目标，美联储倾向加息/维持高利率
  - < 2%：通胀低于目标，美联储倾向降息
  - 核心CPI（剔除食品能源）：更受美联储关注
- **对A股影响**：
  - 美国CPI超预期 → 美联储鹰派 → 美债收益率上行 → 美元走强 → A股外资流出压力
  - 美国CPI低于预期 → 美联储鸽派 → 美债收益率下行 → 美元走弱 → A股外资流入
- **数据来源**：美国劳工统计局（BLS），每月中旬发布
- **AkShare函数**：部分支持，建议辅以Trading Economics / FRED

---

### 美国非农就业（NFP）
- **定义**：美国非农业部门新增就业人数，反映劳动力市场健康度
- **为什么重要**：就业是美联储双重使命之一（通胀+就业），直接影响降息预期
- **怎么看**：
  - 预期±5-10万人：正常波动范围
  - 超预期大幅增长：就业火热 → 美联储鹰派 → 美元走强
  - 不及预期：就业降温 → 美联储鸽派 → 美元走弱
- **对A股影响**：
  - NFP超预期 → 美联储鹰派 → 全球风险资产承压
  - NFP不及预期 → 美联储鸽派 → 全球风险资产受益
- **数据来源**：美国劳工统计局，每月第一个周五发布（美东时间）
- **发布时间**：北京时间晚上20:30（夏令时）或21:30（冬令时）

---

### 美联储利率决议（FOMC）
- **定义**：美联储公开市场委员会制定的基准利率
- **为什么重要**：全球资产定价的锚，直接影响全球流动性环境
- **怎么看**：
  - 降息：释放流动性 → 成长股/新兴市场受益
  - 加息：回收流动性 → 价值股/美元受益
  - 按兵不动：观察期，关注鲍威尔讲话鹰鸽
- **点阵图**：美联储官员对未来利率路径的预期，比决议本身更重要
- **对A股影响**：
  - 降息 → 美债收益率下行 → 全球成长股共振上涨 → A股科技股受益
  - 加息 → 美债收益率上行 → 全球成长股承压 → A股科技股承压
- **发布频率**：每年8次（约每1.5个月一次）
- **重点关注**：3月/6月/9月/12月的会议（发布经济预测和点阵图）

---

### VIX（波动率指数）
- **定义**：衡量S&P 500期权隐含波动率的指数，被称为"恐惧指标"
- **为什么重要**：反映市场对未来30天波动的预期，是情绪和风险的晴雨表
- **怎么看**：
  - < 12：市场自满（Complacency），需警惕突然调整
  - 12 - 20：正常波动范围
  - 20 - 30：较高波动，市场担忧
  - > 30：高波动，市场恐慌（如COVID崩盘时VIX>80）
  - > 35：极度恐慌，往往是逆向买入信号
- **对A股影响**：
  - VIX高企 → 全球Risk-Off → A股外资流出 → 权重股承压
  - VIX低位 → 全球Risk-On → A股外资流入 → 成长股受益
- **数据来源**：CBOE（芝加哥期权交易所）
- **获取方式**：WebSearch 或 `https://finance.yahoo.com/quote/%5EVIX`

## 资金情绪指标

### 北向资金（Northbound Capital）
- **定义**：通过沪股通和深股通流入A股的外资
- **为什么重要**：外资情绪的风向标，单日>50亿为强信号
- **怎么看**：
  - 连续3天净流入 > 50亿/天：外资情绪真实偏多
  - 连续3天净流出 > 50亿/天：外资撤离，需警惕
  - 单日波动可能是偶然，连续同向流动才有意义
- **对A股影响**：
  - 北向净流入 → 外资增持 → 权重股/成长股受益
  - 北向净流出 → 外资减持 → 全市场承压，红利防守占优
- **数据来源**：东方财富，每日盘后更新
- **AkShare函数**：`ak.stock_hsgt_fund_flow_summary_em()`
- **⚠️ 注意事项**：
  - 需筛选`资金方向 == "北向"`
  - 函数名是`stock_hsgt_fund_flow_summary_em`，不是`stock_hsgt_north_flow_summary_em`

---

### 融资余额
- **定义**：投资者向券商借钱买入股票的总金额，反映内资杠杆情绪
- **为什么重要**：融资余额上升=内资加杠杆偏多；下降=去杠杆偏空
- **怎么看**：
  - 连续上升：内资情绪乐观，市场可能过热
  - 连续下降：内资情绪悲观，市场可能超卖
  - 融资余额/流通市值：通常< 3%，超过需警惕杠杆风险
- **对A股影响**：
  - 融资余额上升 → 内资加杠杆 → 风险资产受益
  - 融资余额下降 → 内资去杠杆 → 防守资产占优
- **数据来源**：东方财富，每日盘后更新
- **AkShare函数**：`ak.stock_margin_sse()`（上交所）+ `ak.stock_margin_szse()`（深交所）

## 指标关联关系

```
CPI下行 + PPI上行 = 通胀结构分化，关注中游制造
PMI > 50 + CPI < 1% = 经济复苏但通缩，政策可能宽松
美国CPI超预期 + NFP超预期 = 美联储鹰派，全球Risk-Off
北向资金连续流入 + 融资余额上升 = 内外资共振做多
VIX > 25 + 北向资金流出 = 全球恐慌传导至A股
```
