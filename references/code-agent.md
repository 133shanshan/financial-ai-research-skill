# 可执行推理规范（Code Agent, v3.4.0）

> 本文件定义「金融AI投研」Skill 中**定量推理必须通过代码执行**（而非 LLM 裸算）的规范，对齐 FinSight（ACL 2026）Code Agent「变量空间」范式。
> 核心原则：**定量结论必须来自可执行代码，且可重现（reproducible）**。这是 G1「推导可审计」在计算步的落地闭环——「证据→计算→结论」中的「计算」须由代码完成并留痕。
> 对标：FinSight 变量空间（统一数据/工具/代理）、图表迭代视觉增强（visual verification）。

---

## 一、适用范围（何时必须用 Code Agent）

出现以下任一情形，必须用 Python 代码执行产出，**禁止 LLM 直接给出数值**：

- 任何派生量计算：比率（PE/PB/ROE/净利率）、收益率、增长率、复合增速（CAGR）、估值倍数、相关性、Z-score、打分加权等
- 任何统计/计量结果：回归、显著性、分位、波动率、最大回撤、夏普比率、VaR 等
- 任何图表：折线/柱状/散点/热力图等（须由 matplotlib 等代码生成 PNG，禁止手绘 ASCII 图冒充）
- 回测指标（模块九已走代码，统一归入变量空间）

纯定性叙述（政策取向判断、叙事解读、行业逻辑）不强制代码，但报告中须**显式声明「本报告为定性分析，未含代码执行计算」**（供第六道校验识别）。

---

## 二、变量空间（Variable Space）

所有代码产出的数值统一登记到本次任务的变量空间，路径 `code_workspace/<task_id>/variables.json`（与 `provenance/` 同级，随交付物保存，保证可审计可复现）。

每项变量 schema：

```json
{
  "name": "roe_2025",
  "value": 0.154,
  "unit": "ratio",
  "source_ref": "provenance/src_xxx.json @ [120,180]",
  "code_ref": "code_workspace/<task_id>/scripts/calc.py#L12-L30",
  "env": {"python": "3.13", "libs": ["pandas==2.x", "numpy==1.x"]},
  "computed_at": "2026-07-17T14:30:00"
}
```

- `name` 为全局唯一命名空间 key；report-writer 在正文中引用变量时写「（变量：roe_2025 = 0.154，口径见代码）」。
- `source_ref` 必须指向已锚定快照（G1 provenance）或显式标注的实时源；**未锚定数据不得进入变量空间**。
- `code_ref` 指向可读脚本与行号，确保任何人重跑脚本得到同一数值（可重现性）。
- 同名变量不重复计算；多模块共用同一变量时引用同一 `name`。

---

## 三、代码执行协议

- 使用受管隔离 Python 环境（venv），库版本固定，避免「在我机器上能跑」的不可复现问题。
- 数据入口：优先读 `provenance/` 快照副本或经审计的实时源（AnySearch/AkShare）；**禁止把 LLM 臆造数字当输入**。
- 执行失败 → 走 `references/resilience.md` 重试 ≤3 次（指数退避）；重试耗尽仍失败，**不得用 LLM 编造数值填充**，须标注「计算未执行（环境/数据不可用）」并降级（resilience 矩阵）。
- 脚本与 `variables.json` 随报告交付物一并保存（`code_workspace/` 目录），保证可审计、可复现、可打回重算。

---

## 四、图表生成与视觉校验（FinSight 对齐）

- 图表由代码生成 PNG；生成后必须做**一次视觉校验**：确认无乱码（中文需设字体）、坐标轴/单位/图例正确、无误导性截断或双轴误导。
- 报告中每张图标注「（图表已视觉校验：无误导/乱码）」；若校验发现问题则修订后重出。
- 视觉校验可由 vision 模型或人工完成；降级模式下可标注「图表未经视觉校验（降级）」但须显式声明。

---

## 五、与既有护栏的协同

- 变量空间是 G1 推导链「计算」步的落地；变量须能被 `verify-provenance` / `check-derivation-chain` 追溯到来源。
- 不绕过既有五道 fail-closed 校验（provenance / 推导链 / 反方审计 / 自评估质量门 / 流程韧性声明）。
- **第六道 fail-closed 校验 `check-code-agent.sh`**：报告须含「可执行推理与变量空间」章节且列 ≥1 变量条目（含代码引用），或显式声明「纯定性分析，未执行代码」；否则拦截投递。

详细标杆与规划依据见 技能优化方案 / 金融AI投研Skill优化方案_2026趋势调研.md G3 与 P1-4。
